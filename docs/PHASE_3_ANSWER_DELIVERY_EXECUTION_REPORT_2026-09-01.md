# Phase 3：答案交付与截断恢复执行报告

日期：2026-09-01

## 范围与目标

本阶段严格对应 0901 全项目重审实施计划的 Phase 3（答案交付）。目标是把
“候选被质量门禁拒绝后直接输出 `0`”改为可审计的 L1–L5 答案阶梯，保留原始
模型输出，接通截断打捞和答案净化，同时保持证明题的验证闭环不被降级路径绕过。
本报告区分本地不变量证据与真实 Intern 评测证据；没有用本地测试推导数学准确率。

## 已完成的实现

### 3.1 答案阶梯与原始输出留存

- 新增 `mathforge/harness/answer_ladder.py`，按 L1 已校验候选、L2 未校验候选、
  L3 原始 `\\boxed{}` 打捞、L4 尾部答案式打捞、L5 确定性兜底的顺序选择。
- L2 不再重新套用完整验证器；它表示“答案可交付但未完成验证”，并明确标记
  `degraded`，避免重新制造旧的 all-or-nothing 丢答案路径。
- Provider 观察到的每个原始响应通过 case 级存储保留到终结化，`MathSession`
  仅在内部序列化该字段；公共 trace 不输出原文、提示词或密钥。
- 终结器的 `all_candidates_failed` 分支先走 L3/L4，只有确实没有可打捞答案时
  才使用 L5；`error_code` 保留为诊断字段，不决定答案内容。

### 3.2 韧性答案抽取

- `\\boxed{}` 在剥离 `<think>` 之前和之后均进行扫描；已闭合 think 中的公开答案
  优先，未闭合 think 中的答案可从 salvage 视图恢复。
- 增加英文/中文引导词（如 `The result is`、`Therefore`、`最终答案`、`因此`）
  的回退抽取和尾部答案式抽取。
- 原始响应中的 JSON、标签答案和尾部公式统一经过同一净化函数，保持答案来源
  可追踪且不伪造推导步骤。

### 3.3 质量门禁降级

- `candidate_response_validation(..., allow_degraded=True)` 为求解器候选提供显式
  降级模式：缺字段、非完整 JSON、格式偏差和 nonce 缺失会记录偏差/告警，保留
  可用答案；空答案、占位符和不可恢复的结构错误仍然拒绝。
- 普通生产执行路径保留严格模式；只有自主候选路径明确选择降级模式，避免把
  测试或协议兼容逻辑偷偷变成全局宽松门禁。
- `RecoveredAnswerGate` 为低风险、非证明的可打捞答案提供显式
  `allow_unverified` 入口；高风险/证明题仍要求证据或验证闭合。

### 3.4 答案净化与公共投影

- 新增 `sanitize_final_answer()` 和 `enforce_answer_form()`：截断答案后的提示词
  片段会被裁掉；`<exact answer>`、`<answer>`、`TODO`、模板占位符等命中即视为
  `placeholder_leak`；过长且不像数学表达式的文本会重新尝试抽取答案。
- 占位符命中时公共结果强制 `status=failed`，终结器优先回落 L2/L3，不能再出现
  “占位符外泄但 status=success”。
- 保留公式内部美元符号，修复公共投影重复执行时误删公式结尾分隔符的问题。

### 3.5 Router 与指标接线

- Router 解析使用响应对象提供的 `finish_reason`/截断属性传入真实截断标志，
  激活截断容器闭合；结构化 JSON 失败时尝试 `salvage_top_level_fields()`，无
  可恢复字段时仍 fail-closed。
- `answer_ladder_selected` 纳入内部/评委投影，`answer_source_counts` 统一扩展
  为 L1–L5；旧的两态比较仍可读，但新运行会记录完整分布。

## 验证结果

- 新增 Phase 3 不变量测试 13 项，覆盖阶梯顺序、L2 降级交付、原始 boxed/未闭合
  think、引导词、净化/占位符、长文本回抽、Router 打捞、终结器回落、公共失败
  投影、原始上下文留存及 L1–L5 指标。
- Phase 3 与相关解析、运行时、证明闭环回归测试通过。
- 提交前将执行并记录：`python -m compileall .`、`pytest -q`、
  `python scripts/verify_baseline_files.py`、内容审查指纹、构建 provenance 和
  submission validation。

## Gate 3 证据边界

本阶段只证明答案交付路径和指标接线具备可测试性。尚未使用 88 例带标签语料运行
真实 Gate 3，也未调用 Intern 官方 API 或完成官方 112 例跑批，因此不声称零候选率、
L5 比例、任何数学准确率门槛已经达成。下一步若进行 Gate 3，必须保存逐题公共输出、
答案来源、模型调用时间线和人工/自动评分证据，并单独报告证明题人工复核结果。

## 风险与回滚

- L2/L3/L4 均显式标记降级或来源层级，不能伪装成验证闭合候选；证明题不会因
  `allow_unverified` 自动通过硬证据门禁。
- 原始响应存储受每题调用上限和 case 数上限约束，终结后可释放；公共输出继续
  经过长度、控制字符和占位符保护。
- 若真实评测显示降级答案污染上升，可关闭 `allow_degraded` 或恢复终结器只交付
  L1 的配置分支，而不回滚原始输出留存、净化和指标诊断能力。

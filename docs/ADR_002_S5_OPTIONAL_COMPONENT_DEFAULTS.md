# ADR-002：S5 可选组件保持保守默认

日期：2026-07-23

状态：Accepted for pre-ablation operation

## 背景

S5 需要决定 RAG、MCP 和 LLM Finalizer 在缺少真实重复消融证据时的处理方式。
仓库已经具有这三个可选实现，但当前没有代表性隐藏集、官方公开模型额度和 A0–A10
配对结果，无法证明它们带来稳定净收益。

为了避免把“实现存在”误写成“效果成立”，工程决策与实验结论必须分开。

## 决策

1. RAG 实现保留，`config/competition.json` 默认关闭。仅在 S6 的 A8 配对实验
   同时满足正确率、污染和 P95 门槛后，才考虑默认启用。
2. Direct 工具调用保持默认。一次一进程的本地 StdIO MCP 适配器保留但默认关闭；
   不增加 HTTP MCP，也不创建常驻进程。
3. LLM Finalizer 保留但默认关闭。确定性 Formatter 继续作为生产路径；只有 A10
   同时通过语义不变和净收益门槛后才重新评估。
4. 决策以机器可读的 `config/component_decisions.json` 固化，并进入每次运行的
   provenance。

## 理由

- RAG 已修复原子构建、双语检索和失败诊断，但工程正确性不能替代效果证据。
- MCP 当前没有准确率、隔离性或维护价值优于 Direct 的证据；常驻生命周期会引入
  新状态和故障面。
- Finalizer 位于最终答案边界，收益未证实时不应增加语义漂移风险。

## 后果

- S5 可以验收实现与治理门槛，但不能将竞赛配置标记为 `frozen`。
- S6 必须使用代表性数据和公开模型标识执行重复、配对的 A0–A10 实验。
- 未获得稳定收益的模块继续关闭；不以展示完整性为理由扩大生产路径。
